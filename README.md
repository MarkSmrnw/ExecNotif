# ExecNotif
A notifier if unauthorized apps access folders they should not.

## Use-Cases
 - Maleware attempting to read SessionCookie files inside AppData.
 - Logging and checking for unauthorized access for folders.

## Planned features:
 - Notifications and simple UI for the start, ideas will be added here as time progresses.
 - Custom set HTTP requests to send Notifications out via HTTP (and maybe HTTPs)
